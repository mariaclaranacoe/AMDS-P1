# AMDS-P1
This repository contains the complete codebase, configurations, and documentation for the proponents' thesis: "LLM-Based AI Agent for an IoT-Enabled Mosquito Density and Gender Monitoring System."


models, mosquito_recordings, and environmental_recordings used in this capstone project are found in this github repository: https://github.com/akaraspt/mosquitosongp/tree/main


Manual mosquito trapping and laboratory identification significantly delay local public health actions to insect-borne diseases due to considerable operational latencies. To address this, the study develops the Automated Mosquito Detection System (AMDS-P1), a self-hosted, edge-computed IoT framework created for immediate monitoring of mosquito density and gender. The architecture features an ESP32 edge node integrated with a six-channel laser diode and photodiode sensor array to detect optical beam-breaks, which automatically triggers a localized microphone to capture insect wingbeat frequencies. Telemetry data and binary audio payloads are routed via Wi-Fi, MQTT, and HTTP protocols towards a central Raspberry Pi 4 server gateway running Node-RED and an InfluxDB time-series database.
Empirical testing confirmed high architectural stability and productivity. Field trials involving 53 distinct test entries demonstrated a 100% trigger success rate under tested conditions, while cooldown logic eliminated duplicate counts. For classification, the integrated pretrained Convolutional Neural Network (CNN) achieved an average confidence score of 91.1% across 3 out of 3 verified audio samples. Natural field tests yielded zero false laser triggers during low-activity windows, confirming functional reliability. Finally, a Big Language Model (LLM) agent successfully interpreted data logs to generate public health risk reports, delivered via an n8n automation server at exactly 7:05 AM with low latency. Ultimately, the AMDS-P1 establishes a functional and reliable prototype backbone for automated bio-acoustic public health surveillance
